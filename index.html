About this preview

Prayer times use standard astronomical formulas, adjust automatically for the high-latitude case (long summer nights), and can be fine-tuned by up to 3 hours per prayer above. Qur'an text, translations, and the reciter list are always pulled live from an open Qur'an API, so they stay accurate and keep growing. The adhan plays automatically at each prayer while this app is open, using the muezzin you pick above. "Play full surah" automatically chains individual ayahs together for reciters that don't have a single combined recording.

Two honest limits: a browser tab can't reliably play full-length audio or fire notifications once it's fully closed — the native app build handles real background prayer alerts. And a true lock-screen/home-screen widget isn't possible for a web app at all; that would need the native app compiled with a platform-specific widget extension (see its README).

The Hijri date is calculated (the standard tabular Islamic calendar), not read from a browser calendar API, so it's consistent on every device — it can occasionally be a day off from your local mosque's moon-sighting-based date, same as any calculated Islamic calendar.

Hadith text (Sahih al-Bukhari and Sahih Muslim, Arabic and English) streams live from an open hadith API, same approach as the Qur'an. One honest note: unlike the Qur'an, there isn't a reliable, licensed, per-hadith audio recitation source to draw on, so "Listen" uses your browser's built-in text-to-speech to read the English translation aloud rather than a recorded reciter.

"Announcements" above are powered by OneSignal and are the only notifications in this app that can reach your device when the site is closed — everything else (prayer/du'a reminders, adhan) only runs while this tab is open, which is a browser limitation, not a choice.
